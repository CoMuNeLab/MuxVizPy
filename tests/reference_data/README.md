# muxViz reference data

This directory contains reference results generated by the original muxViz R
package. The committed JSON files let the Python test suite check parity without
installing R or running a container in CI.

The generator requires the muxViz Git commit recorded in `tests/conftest.py`.
It rejects another revision so regenerated values always have explicit
provenance. Generated network CSV files remain under the ignored `tests/data`
directory.

To regenerate the toy reference with an already configured local R environment:

```bash
MUXVIZ_RSCRIPT=/path/to/muxviz-r/bin/Rscript \
  PYTHONPATH=src:tests \
  python -c \
  'from conftest import recompute_muxviz_results; recompute_muxviz_results("toy", existing_results={})'
```

The runner passes `--no-environ` to Rscript. This prevents a user-level
`.Renviron` or `R_LIBS_USER` from replacing packages in the isolated R
environment.
